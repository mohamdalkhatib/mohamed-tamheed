# مهام تمهيد اليومية

صفحة عربية داخلية لتسجيل إنجازات العمل اليومية ومراجعتها شهريًا. التصميم مستوحى من هوية تمهيد، ويعمل باتجاه RTL على الجوال وسطح المكتب.

## المزايا

- إضافة مهمة بعنوان، وصف، وتاريخ تنفيذ.
- حفظ دائم في قاعدة بيانات D1 مع سجل شهري لا يحتوي على إجراء حذف.
- إنشاء شهر جديد مع بقاء الشهور السابقة داخل الأرشيف.
- حالات اعتماد ثلاثية: في الانتظار، معتمدة، وغير معتمدة.
- جلسة مشرف آمنة عبر Cookie محمية، مع حفظ مشتق كلمة المرور خارج المستودع.
- واجهة متجاوبة وتصفية سريعة حسب حالة الاعتماد.

## التشغيل المحلي

يتطلب المشروع Node.js 22 أو أحدث. انسخ `.env.example` إلى `.env`، وضع قيمة `SUPERVISOR_PASSWORD_HASH`، ثم شغّل:

```bash
npm ci
npm run dev
```

للتحقق من نسخة الإنتاج:

```bash
npm test
```

كلمة مرور المشرف لا تُحفظ داخل GitHub، وتُضبط كمتغير سري في بيئة الاستضافة.
